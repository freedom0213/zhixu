# 知序学堂平台使用指南

本指南介绍知序学堂平台的功能、购课流程与学习路线建议，供平台 AI 助手回答用户问题时引用。

## 一、平台简介

知序学堂是一个面向编程与 IT 技能方向的在线学习平台，提供课程浏览、选课购买、在线学习、章节练习、在线考试、学习笔记、收藏、积分与优惠券等功能，并为学习过程提供 AI 助手支持。

平台课程按「大类 / 分类 / 三级分类」组织，用户可在课程列表页按分类筛选与关键词搜索。具体可选课程以平台课程列表页实时展示为准。

## 二、平台功能介绍

### 课程浏览与搜索

- 首页与课程列表页展示平台课程，可按分类体系筛选。
- 支持关键词搜索，支持按综合、价格、销量等维度排序。
- 课程卡片展示课程名称、分类、价格（或"免费"）与课时节数。

### 选课与购买

- 用户可将课程加入购物车，或直接点击"立即购买"。
- 结算页可确认课程、使用优惠券，提交订单后完成支付。
- 免费课程无需支付，可直接开始学习。

### 在线学习

- 进入课程详情页后，可在「目录 / 问答 / 笔记 / AI助教」之间切换。
- 学习页支持按章节学习、做笔记、做练习题。
- 已购课程可在「个人中心 → 我的课程」中继续学习。

### 三个 AI 助手的分工

- 全局 AI 助手：首页右下角悬浮图标打开，负责平台层面的引导，包括推荐课程、规划学习路线、说明平台功能与购课流程。
- 课程 AI 助教：在课程详情页内，自动绑定当前课程，基于本课程资料讲解知识点、做章节总结、生成练习题、进行知识检测。
- 私人 AI 学习助手：独立页面（"我的 AI 学习助手"），用户可上传自己的 Markdown / TXT 笔记，基于个人资料进行问答、笔记整理、内容检查、自动出题、学习计划制定。

### 考试与练习

- 课程可包含随堂练习与在线考试，在个人中心可查看考试记录与成绩。

### 笔记、收藏与问答

- 学习过程中可记录笔记，可收藏课程，可在课程问答区提问与查看他人提问。

### 积分、优惠券与订单

- 平台设有积分与积分商城，可通过学习等行为获得积分。
- 优惠券可在结算页选择使用。
- 订单与支付记录可在「个人中心」查看。

## 三、如何购买课程

购买课程的标准流程如下：

1. 注册并登录知序学堂账号。
2. 在首页或课程列表页找到目标课程，也可使用搜索或分类筛选。
3. 在课程详情页点击"加入购物车"或"立即购买"。
4. 进入结算页，确认课程信息，如有优惠券可选择使用。
5. 提交订单并完成支付。
6. 支付成功后，在「个人中心 → 我的课程」中即可开始学习。

### 购课常见问题

- 免费课程：标注为"免费"的课程无需支付，登录后可直接学习。
- 优惠券：在结算页选择可用的优惠券，系统会自动抵扣。
- 订单查询：所有订单与支付状态可在「个人中心」的订单页面查看。
- 买错或想退：可在订单页面查看订单状态，并联系平台客服处理。

## 四、学习路线建议

平台可结合用户的基础与目标推荐学习路线。以下是两条常见路线的阶段建议（具体课程请以平台课程列表中的实际课程为准）。

### Java 学习路线

1. 编程基础与计算机常识。
2. Java 语言基础与面向对象。
3. Java 集合与并发编程。
4. JVM 原理与性能调优。
5. 数据库基础，重点是 MySQL 的索引与优化。
6. Web 开发与主流框架，如 Spring Boot。
7. 微服务与分布式，涉及 Spring Cloud、Redis、消息队列、网关等。
8. 综合项目实战，串联所学知识。

### Python 学习路线

1. Python 编程基础与语法。
2. 数据处理与常用库。
3. Web 开发，如 Flask / Django 方向。
4. 自动化脚本与工程实践。
5. 综合项目实战。

### 通用学习建议

- 先打基础再上进阶，避免跳步。
- 边学边练，配合课程练习与考试巩固。
- 遇到课程内的知识点疑问，进入对应课程的「AI助教」提问，能得到基于该课程资料的更准确回答。

## 五、如何选择课程

- 明确学习目标与当前基础，再选择对应层级与方向的课程。
- 使用分类筛选与搜索缩小范围，优先选择有成体系目录的课程。
- 不确定学什么时，可以让平台 AI 助手根据你的目标推荐课程，并给出学习顺序建议。
- 具体课程的分类、价格与课时，请以平台课程列表页展示的实时信息为准。
