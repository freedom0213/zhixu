## 第一章 Python 入门

本章完成环境准备并建立对 Python 语法风格的第一印象。

### 1.1 环境与第一个程序

**学习目标**：能安装 Python 并运行第一个脚本。

**核心知识点**

- Python 是解释型语言，代码逐行解释执行，无需编译步骤
- 缩进在 Python 中是语法的一部分，用缩进表示代码块而不是花括号
- 运行方式有交互式解释器与脚本文件两种，调试小段代码适合交互式
- 使用 python --version 确认版本，第三方依赖通过 pip 安装

**示例**

```python
print("Hello, Python")
# 运行：python hello.py
```

**易错点**：混用 Tab 与空格缩进会报 IndentationError，同一文件应统一使用 4 个空格。

### 1.2 变量与数据类型

**学习目标**：掌握基本数据类型与动态类型的特点。

**核心知识点**

- 基本类型：int、float、str、bool、NoneType
- Python 是动态类型语言，变量不需要声明类型，类型由运行时赋的值决定
- 类型可转换：int()、float()、str()，转换失败会抛 ValueError
- 字符串不可变，所有看似修改的操作实际都会返回新字符串

**示例**

```python
name = "张三"
age = 20
height = 1.75
is_student = True
print(type(age))   # <class 'int'>
```

**易错点**：把输入得到的字符串直接参与数学运算，input() 返回的永远是字符串，必须先 int() 转换。

### 1.3 运算符与输入输出

**学习目标**：掌握算术、比较、逻辑运算符与格式化输出。

**核心知识点**

- / 是真除法返回浮点，// 是整除向下取整，% 取余，** 是幂运算
- and、or、not 用于逻辑运算，且具有短路特性
- 推荐用 f-string 做字符串格式化，可读性最好
- input() 返回字符串类型，需要数值时必须显式转换

**示例**

```python
a = 7 // 2      # 3
b = 7 % 2       # 1
c = 2 ** 10     # 1024
name = input("请输入姓名：")
print(f"你好，{name}")
```

**易错点**：用 / 做整除期望得到整数，实际返回浮点数，整除应使用 //。

## 第二章 流程控制与函数

本章让程序具备分支、循环与复用能力。

### 2.1 条件与循环

**学习目标**：掌握 if-elif-else 与 for、while 的写法及控制语句。

**核心知识点**

- if-elif-else 自上而下匹配，命中一个分支后其余分支不再判断
- for 用于遍历可迭代对象，while 用于条件为真时反复执行
- range(start, stop, step) 生成整数序列，stop 不包含在内
- break 跳出整个循环，continue 跳过本次进入下一次

**示例**

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
total = 0
n = 1
while n <= 100:
    total += n
    n += 1
```

**易错点**：while 循环忘记更新循环变量会导致死循环，必须在循环体内改变判断条件。

### 2.2 函数定义与参数

**学习目标**：掌握函数定义、返回值与各类参数形式。

**核心知识点**

- 用 def 定义函数，return 返回值，没有 return 时默认返回 None
- 参数类型包括位置参数、默认参数、可变参数 *args 与关键字参数 **kwargs
- 默认参数不要在函数定义时使用可变对象，否则会在多次调用间共享
- 函数可以返回多个值，实际返回的是一个元组

**示例**

```python
def calc(a, b=10):
    return a + b, a * b

s, p = calc(2)
print(s, p)   # 12 20
```

**易错点**：把默认参数写成 def f(items=[])，多次调用会共用同一个列表，应改为 items=None 再在函数体内初始化。

### 2.3 作用域与内置函数

**学习目标**：理解变量作用域与常用内置函数的使用。

**核心知识点**

- 函数内赋值会创建局部变量，读取时可访问全局变量，修改全局需用 global 声明
- LEGB 查找顺序：局部 → 闭包 → 全局 → 内置
- 常用内置函数：len、sum、max、min、sorted、enumerate、zip
- sorted 返回新列表，list.sort() 原地排序并返回 None

**示例**

```python
nums = [3, 1, 2]
print(sorted(nums))      # [1, 2, 3]
print(sorted(nums, reverse=True))
for idx, val in enumerate(nums):
    print(idx, val)
```

**易错点**：写成 nums = nums.sort()，sort() 返回 None，会导致列表被替换成 None。

## 第三章 常用数据结构与实战

本章讲清四种容器的差异与选择，并补上文件与异常处理。

### 3.1 列表与元组

**学习目标**：掌握可变序列与不可变序列的区别与常用操作。

**核心知识点**

- 列表用 [] 定义、可变，支持增删改查；元组用 () 定义、不可变
- 常用方法：append、extend、insert、remove、pop、index、count
- 切片 lst[start:stop:step] 返回新列表，左闭右开，支持负数索引
- 元组可作为字典的键，列表不可以，因为字典键必须可哈希

**示例**

```python
lst = [1, 2, 3]
lst.append(4)
print(lst[1:3])       # [2, 3]
print(lst[::-1])      # 反转
point = (10, 20)
```

**易错点**：把列表赋值给另一个变量后再修改，两个变量指向同一对象会同时改变，需要副本时应使用切片或 copy()。

### 3.2 字典与集合

**学习目标**：掌握键值映射与去重集合的常用操作。

**核心知识点**

- 字典用 {key: value} 定义，键唯一且必须可哈希，查询平均复杂度为 O(1)
- dict.get(key, default) 在键不存在时返回默认值，避免 KeyError
- 集合用 {} 或 set() 定义，元素唯一且无序，适合去重与集合运算
- 常用集合运算：并集 |、交集 &、差集 -

**示例**

```python
scores = {"张三": 90, "李四": 85}
print(scores.get("王五", 0))   # 0
for k, v in scores.items():
    print(k, v)
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)   # {2, 3}
```

**易错点**：用 d[key] 读取可能不存在的键会抛 KeyError，不确定键是否存在时应使用 get()。

### 3.3 文件读写与异常处理

**学习目标**：能安全地读写文件并优雅处理错误。

**核心知识点**

- with open(path, "r", encoding="utf-8") as f 会在块结束时自动关闭文件
- 模式：r 读、w 覆盖写、a 追加，带 b 表示二进制模式
- try-except-else-finally 处理异常，捕获应尽量具体而不要一律 except Exception
- 读写文件时显式指定 encoding="utf-8"，避免中文在 Windows 下乱码

**示例**

```python
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")

try:
    with open("data.txt", "r", encoding="utf-8") as f:
        print(f.read())
except FileNotFoundError:
    print("文件不存在")
```

**易错点**：手动 open 后忘记 close，在异常路径下会泄漏文件句柄，应统一使用 with 语句。

## 综合练习

### 单项选择题

**1. Python 中用于表示代码块的方式是？**

- A. 花括号 {}
- B. 缩进
- C. begin/end 关键字
- D. 分号

**答案**：B

**解析**：Python 用缩进表示代码块，缩进是语法的一部分，混用 Tab 与空格会导致 IndentationError。

**对应知识点**：语法基础

**2. 表达式 7 // 2 的结果是？**

- A. 3.5
- B. 3
- C. 4
- D. 1

**答案**：B

**解析**：// 是整除运算符，向下取整；/ 才是真除法会返回 3.5，% 是取余返回 1。

**对应知识点**：运算符

**3. 关于字典的说法，正确的是？**

- A. 字典的键可以是列表
- B. 字典的键必须可哈希且唯一
- C. 字典是有序的可重复集合
- D. 读取不存在的键会返回 None 而不会报错

**答案**：B

**解析**：字典键必须可哈希且唯一，列表不可哈希所以不能作为键；直接以 d[key] 读取不存在的键会抛 KeyError。

**对应知识点**：字典

**4. 以下哪种方式是推荐的字符串格式化写法？**

- A. f-string
- B. % 格式化
- C. str.format()
- D. 字符串拼接

**答案**：A

**解析**：f-string 语法简洁、可读性最好，且执行效率较高，是当前推荐的格式化方式。

**对应知识点**：输入输出

**5. 关于 list.sort() 的描述，正确的是？**

- A. 返回排序后的新列表
- B. 原地排序并返回 None
- C. 只能对字符串列表排序
- D. 原地排序并返回排序后的列表

**答案**：B

**解析**：list.sort() 原地排序并返回 None，若需要新列表应使用内置函数 sorted()。

**对应知识点**：内置函数

### 判断题

**1. Python 中元组是不可变的，因此可以作为字典的键。**

**答案**：正确

**解析**：正确。元组不可变且可哈希，可以作为字典键；列表不可哈希，不能作为键。

**对应知识点**：列表与元组

**2. 函数定义时写成 def f(items=[]) 是安全的，每次调用都会得到一个新的空列表。**

**答案**：错误

**解析**：错误。默认参数在函数定义时只求值一次，可变默认对象会在多次调用之间共享，应改为 items=None。

**对应知识点**：函数默认参数

**3. 使用 with open(...) as f 可以保证文件在代码块结束时被自动关闭，即使中途抛出异常。**

**答案**：正确

**解析**：正确。with 语句依赖上下文管理器，无论正常结束还是抛异常都会执行关闭操作。

**对应知识点**：文件读写
