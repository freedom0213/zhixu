# 算法入门：排序与查找

> 本文件为「知序学堂」课程知识库资料，供课程 AI 助教检索与问答使用。

## 课程简介

系统掌握经典排序与查找算法，理解其复杂度与适用场景。

本课程先建立算法分析与递归分治的基础，再逐一讲解冒泡、选择、插入、归并、快速、堆排序与非比较排序，最后覆盖顺序查找、二分查找及其边界处理与哈希查找等常用手段。

## 第一章 算法分析基础

本章提供比较与设计算法的思维工具。

### 1.1 算法与复杂度

**学习目标**：能从时间与空间两个维度评价算法。

**核心知识点**

- 算法是解决特定问题的有限步骤序列，需具备有穷性、确定性、可行性与输入输出
- 时间复杂度关注基本操作执行次数随规模的增长趋势
- 空间复杂度关注额外空间占用，原地算法额外空间为 O(1)
- 工程中要结合数据规模与分布选择算法，而不是只看渐近复杂度

**示例**

数据量小且基本有序时，插入排序常优于快速排序
数据量巨大且对稳定性有要求时，归并排序更合适

**易错点**：只看最坏复杂度而忽略常数与数据分布，导致在小数据量场景选错算法。

### 1.2 递归与分治

**学习目标**：掌握递归三要素与分治的拆解思路。

**核心知识点**

- 递归三要素：明确函数语义、确定终止条件、推导递推关系
- 分治把问题拆成若干规模更小的同类子问题，求解后合并结果
- 归并排序与快速排序都是分治思想，区别在于拆解与合并的方式
- 递归需注意重复计算问题，可用记忆化或改写为动态规划优化

**示例**

归并：拆到单个元素（天然有序）→ 两两合并有序数组
快排：选基准分区 → 左右子区间分别递归

**易错点**：忘记写终止条件或递推规模不收敛，会导致无限递归与栈溢出。

### 1.3 稳定性与原地性

**学习目标**：理解排序算法的两个重要工程属性。

**核心知识点**

- 稳定性指相等元素的相对顺序在排序后保持不变
- 需要多关键字排序时稳定性很重要，例如先按分数排序再按班级排序
- 原地性指只用 O(1) 额外空间，对内存敏感场景很关键
- 冒泡、插入、归并稳定；选择、快排、堆排序不稳定

**示例**

先按姓名排序，再用稳定排序按班级排序，同班内仍保持姓名有序

**易错点**：认为快排稳定，实际快速排序在分区交换时会打乱相等元素的相对顺序。

## 第二章 排序算法

本章覆盖从基础到高级的排序算法族。

### 2.1 冒泡、选择与插入排序

**学习目标**：掌握三种 O(n²) 基础排序及各自特点。

**核心知识点**

- 冒泡排序相邻比较交换，每轮把最大值冒到末尾，可加标志位提前退出
- 选择排序每轮选出最小值放到已排区间末尾，交换次数最少
- 插入排序把当前元素插入已排好序的前缀中，对基本有序的数据效率很高
- 插入排序在实践中常作为小数组的补充排序被高级算法调用

**示例**

```java
// 插入排序
for (int i = 1; i < n; i++) {
    int cur = a[i], j = i - 1;
    while (j >= 0 && a[j] > cur) { a[j + 1] = a[j]; j--; }
    a[j + 1] = cur;
}
```

**易错点**：插入排序移动元素时忘记暂存当前值，会被后续移动覆盖而丢失数据。

### 2.2 归并与快速排序

**学习目标**：掌握两种 O(n log n) 主力排序的实现与取舍。

**核心知识点**

- 归并排序稳定、最坏也是 O(n log n)，但需要 O(n) 额外空间
- 快速排序平均 O(n log n)、原地、常数小，是最常用的通用排序
- 快排的关键是分区，常用双指针或挖坑法，基准选择影响性能
- 快排在有序数据上用首元素作基准会退化为 O(n²)，可随机选基准或三数取中

**示例**

```java
// 快排核心：分区后基准归位
int p = partition(a, lo, hi);
quickSort(a, lo, p - 1);
quickSort(a, p + 1, hi);
```

**易错点**：对已排序数组固定取首元素作基准，递归深度达到 n，既慢又有栈溢出风险。

### 2.3 堆排序与非比较排序

**学习目标**：理解堆结构与线性时间排序的适用条件。

**核心知识点**

- 堆是完全二叉树，大顶堆满足父节点不小于子节点，可用数组存储
- 堆排序先建堆再反复取堆顶，时间复杂度稳定 O(n log n)，且原地、最坏也是该量级
- 计数排序适用于数值范围较小的整数，复杂度 O(n + k)
- 基数排序按位依次排序，桶排序按区间分桶，均要求数据满足特定条件

**示例**

```java
// 堆化：从最后一个非叶子节点向前下沉
for (int i = n / 2 - 1; i >= 0; i--) siftDown(a, i, n);
```

**易错点**：在有负数或数值范围极大的数据上使用计数排序，会造成数组越界或空间爆炸。

## 第三章 查找算法

本章讲清从线性到对数级查找的演进。

### 3.1 顺序查找与二分查找

**学习目标**：掌握二分查找的前提与实现。

**核心知识点**

- 顺序查找逐个比较，复杂度 O(n)，适用于无序且规模小的数据
- 二分查找要求数据有序，复杂度 O(log n)，每次排除一半区间
- 循环写法中 mid 用 lo + (hi - lo) / 2 计算可避免整数溢出
- 二分查找的循环不变量必须在整个过程中保持一致

**示例**

```java
int lo = 0, hi = n - 1;
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;
    if (a[mid] == target) return mid;
    else if (a[mid] < target) lo = mid + 1;
    else hi = mid - 1;
}
return -1;
```

**易错点**：边界更新写成 lo = mid 或 hi = mid，在区间只剩两个元素时会陷入死循环。

### 3.2 二分答案与边界处理

**学习目标**：掌握查找左右边界的写法与二分答案思想。

**核心知识点**

- 查找第一个等于 target 的位置，需要在命中时继续收缩右边界
- 查找最后一个等于 target 的位置，需要在命中时继续收缩左边界
- 二分答案把「求解最优值」转化为「判断某个值是否可行」，适合单调性明确的问题
- 使用左闭右开区间 [lo, hi) 的写法可以统一边界处理，减少特判

**示例**

```java
// 找左边界
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (a[mid] >= target) hi = mid;
    else lo = mid + 1;
}
return lo;
```

**易错点**：直接把「找到即返回」的二分用于求边界问题，会返回任意一个匹配位置而非最左或最右位置。

### 3.3 哈希查找

**学习目标**：理解哈希查找的复杂度与适用条件。

**核心知识点**

- 哈希查找通过键直接定位，平均复杂度 O(1)，但不支持范围查询与有序遍历
- 哈希查找需要额外空间，且元素顺序无法保证
- 需要同时满足等值查找与范围查找时，应选择平衡树而非哈希表
- 处理海量数据去重或存在性判断时，哈希与布隆过滤器常被组合使用

**示例**

等值查询为主 → 哈希表
需要范围查询或有序遍历 → 平衡树（如 Java 的 TreeMap）

**易错点**：用哈希表做范围查询，只能全表扫描，此时应改用有序结构。

## 综合练习

### 单项选择题

**1. 以下排序算法中，属于稳定排序的是？**

- A. 快速排序
- B. 堆排序
- C. 归并排序
- D. 选择排序

**答案**：C

**解析**：归并排序在合并时保持相等元素的相对顺序，是稳定排序；快排、堆排序与选择排序都不稳定。

**对应知识点**：稳定性

**2. 快速排序在最坏情况下的时间复杂度是？**

- A. O(n)
- B. O(n log n)
- C. O(n²)
- D. O(log n)

**答案**：C

**解析**：当基准选择不当导致分区极不平衡时会退化为 O(n²)，如对有序数组固定取首元素作基准。

**对应知识点**：快速排序

**3. 对基本有序的数据进行排序，效率表现突出的是？**

- A. 插入排序
- B. 选择排序
- C. 堆排序
- D. 计数排序

**答案**：A

**解析**：插入排序在数据基本有序时比较与移动次数都很少，接近 O(n)，是实践中的优选。

**对应知识点**：插入排序

**4. 计数排序要求数据满足什么条件？**

- A. 必须是有序的
- B. 必须是整数且数值范围较小
- C. 必须是浮点数
- D. 必须没有重复元素

**答案**：B

**解析**：计数排序用数组下标对应数值，要求数据为整数且取值范围较小，否则空间开销会爆炸。

**对应知识点**：非比较排序

**5. 二分查找要求输入数据具备什么前提？**

- A. 无序
- B. 有序
- C. 无重复
- D. 为整数

**答案**：B

**解析**：二分查找依赖有序性来每次排除一半区间，因此必须先保证数据有序。

**对应知识点**：二分查找

### 判断题

**1. 归并排序的时间复杂度在最坏情况下仍为 O(n log n)，但需要 O(n) 的额外空间。**

**答案**：正确

**解析**：正确。归并排序性能稳定但需要额外数组用于合并，空间换取了确定性的 O(n log n)。

**对应知识点**：归并排序

**2. 哈希表既能高效支持等值查找，也能高效支持范围查询。**

**答案**：错误

**解析**：错误。哈希表平均等值查找为 O(1)，但元素无序，范围查询只能退化为全表扫描。

**对应知识点**：哈希查找

**3. 二分查找中 mid 使用 lo + (hi - lo) / 2 计算，可以避免 lo + hi 造成的整数溢出。**

**答案**：正确

**解析**：正确。lo + hi 在接近整数上限时可能溢出，改写为 lo + (hi - lo) / 2 可规避该问题。

**对应知识点**：二分实现
